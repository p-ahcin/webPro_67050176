# MiniShop Dashboard

เว็บแอปพลิเคชันสำหรับเลือกซื้อสินค้าและจัดการสต็อกในรายวิชา Web Programming
รองรับการค้นหา กรองหมวดหมู่ ตะกร้าสินค้า โปรไฟล์ และ Admin Dashboard
พัฒนาด้วย React, Vite, React Router, Tailwind CSS และ DaisyUI

## เริ่มใช้งาน

ต้องมี Node.js `^20.19.0` หรือ `>=22.12.0` และ npm

จากโฟลเดอร์ราก `webPro`:

```powershell
cd .\finalWeb0176\minishop-dashboard
npm ci
npm run dev
```

เปิด URL ที่ Terminal แสดง โดยทั่วไปคือ [http://localhost:5173](http://localhost:5173)
หากพอร์ตถูกใช้งาน Vite อาจเลือกพอร์ตอื่น
แอปเรียก Public API โดยตรง จึงใช้เพียง Terminal เดียว

> [!IMPORTANT]
> รันคำสั่ง npm ภายในโฟลเดอร์ `minishop-dashboard` ที่มี `package.json`
> และ `package-lock.json` ไม่ใช่โฟลเดอร์ชั้นนอก `finalWeb0176`

| คำสั่ง | การทำงาน |
| --- | --- |
| `npm ci` | ติดตั้ง dependencies ตาม `package-lock.json` |
| `npm run dev` | เปิดเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | สร้างไฟล์สำหรับใช้งานจริงใน `dist/` |
| `npm run preview` | เปิดดูผล build ในเครื่อง โดยต้อง build ก่อน |

## ความสามารถ

- **หน้าร้าน:** Banner สินค้าแนะนำ หมวดหมู่ และปุ่ม Add to Cart
- **รายการสินค้า:** ค้นหาชื่อโดยไม่แยกตัวพิมพ์เล็กใหญ่ กรองหมวดหมู่ร่วมกัน
  และล้างตัวกรองได้
- **รายละเอียดสินค้า:** รูปภาพ คำอธิบาย ราคา คะแนนรีวิว และสถานะสต็อก
- **ตะกร้าสินค้า:** ปรับจำนวนภายในสต็อก ลบรายการ และสรุปราคารวม
- **โปรไฟล์:** แก้ไขชื่อ อีเมล ที่อยู่ และดูประวัติคำสั่งซื้อ
- **Admin:** เพิ่ม แก้ไข ลบสินค้า พร้อมสถิติ กราฟสต็อก และรายการคำสั่งซื้อ
- **การแสดงผล:** รองรับมือถือ แท็บเล็ต เดสก์ท็อป และ Light/Dark Mode
  พร้อม Loading, Error และข้อความเมื่อไม่พบสินค้า

## หน้าและเส้นทาง

| URL | หน้าที่ |
| --- | --- |
| `/` | Home พร้อม Banner สินค้าแนะนำ และหมวดหมู่ |
| `/products` | ค้นหา กรอง ดูรายละเอียด และเพิ่มสินค้าลงตะกร้า |
| `/products/:id` | รายละเอียดสินค้าตาม ID |
| `/cart` | ตะกร้า ปรับจำนวน สรุปยอด และสั่งซื้อ |
| `/profile` | โปรไฟล์ผู้ใช้และประวัติคำสั่งซื้อ |
| `/admin` | เปลี่ยนเส้นทางไป `/admin/dashboard` |
| `/admin/dashboard` | สรุปสินค้า กราฟสต็อก ยอดขาย และคำสั่งซื้อ |
| `/admin/products` | เพิ่ม แก้ไข และลบสินค้า |
| `/about` | ข้อมูลเกี่ยวกับแอปพลิเคชัน |
| URL อื่น | หน้า 404 |

ใช้เมนู **Admin → Manage Products** เพื่อจัดการสินค้า
ฟอร์มเพิ่ม/แก้ไขและปุ่ม Delete แสดงเฉพาะ `/admin/products`
โดยหน้า Products และ Admin ใช้ข้อมูลสินค้าชุดเดียวกันผ่าน React Context
การเปลี่ยนหน้าด้วย React Router ไม่โหลดหน้าเว็บใหม่

## แหล่งข้อมูลและการคำนวณ

เมื่อเปิดแอป ระบบเรียก `GET https://fakestoreapi.com/products`
ด้วย `fetch()` ภายใน `useEffect()` และจัดการผลด้วย `async/await`
โค้ดเชื่อมต่ออยู่ที่ [productApi.js](./src/service/productApi.js)

- แปลงฟิลด์ `title` จาก API เป็น `name` ที่ใช้ในแอป
- เติม `stock` จำลอง เพราะ API ไม่มีข้อมูลสต็อก
- อ่านคะแนนและจำนวนรีวิวจาก `rating.rate` และ `rating.count`
- ใช้รูปจาก `image` และแสดงภาพแทนเมื่อไม่มีรูปหรือโหลดรูปไม่ได้
- แสดง Loading ระหว่างรอ และแจ้งข้อผิดพลาดเมื่อเรียกข้อมูลไม่สำเร็จ
- หาก API ล้มเหลวหรือใช้เวลาเกิน 10 วินาที จะใช้ข้อมูลสำรอง 5 รายการ
  จาก [sampleProducts.js](./src/sampleProducts.js)

กด **ใช้ข้อมูลตามข้อสอบ** เพื่อเปลี่ยนเป็นชุดข้อมูลตัวอย่าง
หรือกด **โหลด API ใหม่** เพื่อลองดึงข้อมูลอีกครั้ง
ทั้งสองปุ่มจะเริ่มรายการสินค้าและตะกร้าใหม่ แต่เก็บประวัติคำสั่งซื้อในรอบนั้นไว้

ฟอร์มตรวจว่าชื่อไม่ว่าง ราคาต้องเป็นตัวเลขมากกว่า 0
และสต็อกต้องเป็นจำนวนเต็มตั้งแต่ 0 ขึ้นไป
สินค้าหมดสต็อกจะแสดง Out of Stock และปิดปุ่ม Add to Cart

> [!NOTE]
> การเพิ่ม แก้ไข ลบ โปรไฟล์ ตะกร้า และคำสั่งซื้อจัดการด้วย React State
> ข้อมูลอยู่ระหว่างการเปลี่ยนหน้าภายในแอป แต่เริ่มใหม่เมื่อรีเฟรช
> ค่าธีมเท่านั้นที่บันทึกใน `localStorage`

การสั่งซื้อเป็นการจำลอง ไม่มีการชำระเงินจริง
เมื่อสั่งซื้อจะหักสต็อก ล้างตะกร้า และแสดงคำสั่งซื้อใน Profile กับ Admin
ยอดขายคำนวณจากคำสั่งซื้อในรอบการใช้งานนั้น
แอปไม่มีระบบยืนยันตัวตน และการแก้ไขสินค้าไม่ส่งกลับไปเขียนข้อมูลบน API
ราคาจาก API ใช้ตัวเลขเดิมและแสดงเป็นบาทเพื่อการฝึก ไม่มีการแปลงอัตราแลกเปลี่ยน

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| `ENOENT` หา `package.json` ไม่เจอ | เข้าโฟลเดอร์ `minishop-dashboard` ก่อนรัน npm |
| `npm ci` แจ้งว่าไม่มี lockfile | ตรวจว่ารันในโฟลเดอร์ที่มี `package-lock.json` |
| `EPERM` ลบไฟล์ `.node` ไม่ได้บน Windows | หยุด Vite ด้วย Ctrl+C ใน Terminal ที่รันอยู่ แล้วลอง `npm ci` ใหม่ |
| เปิดมาเห็นข้อมูลสำรอง | ตรวจอินเทอร์เน็ต ปิดโหมด Offline แล้วกดโหลด API ใหม่ |
| ไม่เห็นปุ่มเพิ่ม แก้ไข หรือลบ | เข้า Admin → Manage Products |
