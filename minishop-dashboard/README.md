# MiniShop React

ต่อยอดจาก MiniShop เดิมตามใบงาน Week 6–8 โดยใช้ Vite, React และ Tailwind CSS

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal

## ส่วนที่ทำตามใบงาน

- แยก `Header`, `ProductCard`, `ProductList` และ `Profile` เป็น React components
- ส่งชื่อ ราคา รูป และหมวดหมู่สินค้าเข้า `ProductCard` ผ่าน props
- ใช้ `useState` สำหรับจำนวนสินค้าในตะกร้า การค้นหา ตัวกรอง และหน้าที่เปิดอยู่
- ใช้ `onClick` และ `onChange` สำหรับการโต้ตอบ
- ใช้ `useEffect` โหลดสินค้าจาก `https://fakestoreapi.com/products`
- แสดงสถานะกำลังโหลด ข้อผิดพลาดพร้อมปุ่มลองใหม่ และผลการค้นหาที่ว่างเปล่า
- เพิ่มตัวกรองหมวดหมู่ การเรียงราคา หน้ารายละเอียดสินค้า และรายการในตะกร้า

หาก API ไม่ตอบกลับภายใน 12 วินาที หรือโหลดไม่สำเร็จ แอปจะแจ้งข้อผิดพลาดและแสดงสินค้าตัวอย่างจากงานเดิม เพื่อให้ทดลองค้นหาและตะกร้าได้ ปุ่ม Try Again จะลองโหลดข้อมูลจาก API ใหม่
